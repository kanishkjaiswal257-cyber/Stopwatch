# ⏱️ Precision Stopwatch

A sleek, responsive, and high-precision stopwatch web application built with React and Vite.

## ✨ Features

- **High Precision Timing**: Smooth elapsed time tracking with millisecond/centisecond precision.
- **Lap & Split Tracking**: Record laps on the fly with dynamic lap time calculation.
- **Keyboard Shortcuts**: Press <kbd>Space</kbd> to toggle start/pause quickly.
- **Responsive & Modern UI**: Clean visual styling designed for all screen sizes.

## 🚀 Getting Started

### Prerequisites

- Node.js (version 18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/kanishkjaiswal257-cyber/Stopwatch.git
   cd Stopwatch
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vite.dev/)
- **Styling**: Vanilla CSS
- **Linter**: [Oxlint](https://oxc.rs/)
